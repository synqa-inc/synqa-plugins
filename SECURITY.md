# Security

## Report a problem privately

If you find a security problem in this catalog or in a plugin listed here, report it through GitHub's private vulnerability reporting on this repository.

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability**.
3. Describe what you found, which plugin it affects and how to see it.

Do not open a public issue or a public pull request for a security problem. Public reports put every user at risk before a fix exists.

## What happens next

A Synqa reviewer reads the report, confirms the problem and decides whether to fix or remove the plugin. We will tell you what we decided.

## What counts

- A plugin that runs or loads code, although plugins here must be code-free.
- A file that tries to reach another site, read private data or hide its purpose.
- A plugin that uses a reserved `synqa` name without being published by `synqa-inc`.
- A plugin that misstates its authors, sources or license.
